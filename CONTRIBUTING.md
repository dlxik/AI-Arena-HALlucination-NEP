# Contributing

1. Tạo branch từ `dev`; không commit trực tiếp vào `main`.
2. Không đưa secret, API key hoặc dữ liệu cá nhân vào repository.
3. Mọi khẳng định văn hóa phải có nguồn thật và được reviewer phê duyệt.
4. Giữ prompt theo phiên bản; ghi thay đổi đáng kể vào `docs/ai-log.md`.
5. Chạy `npm run lint`, `npm run typecheck`, `npm run validate:data` và `npm run build` trước khi mở pull request.

Các record `draft` hoặc `needs_review` không được trình bày là dữ kiện đã kiểm chứng.
